# Screenshots

Drop exported UI screenshots here, then reference them in the root `README.md` table, e.g.:

```markdown
![Home](./docs/screenshots/home.png)
```

Suggested filenames matching the root README table:
- `home.png`
- `campaign-details.png`
- `donation-flow.png`
- `admin-dashboard.png`

Export from Figma: select the frame → right panel → Export → PNG, 2x scale.
